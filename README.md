# translate-any-games

Instructions for AI. They help it write a translation by using their own tool for games.

# Disclaimer

> [!IMPORTANT]
> This repo is for personal use. It is shared as is. It is not maintained, and no updates or support are planned.
> If you need something changed, fork the repo and do it yourself.
> It is not affiliated with any game developer or publisher.

> [!WARNING]
> - Use this only on games you own, for your own use.
> - This repo contains no game files, and it must not contain any.
> - Do not share or sell a modified game, or any game text you did not write, without permission from the rights holder.
> - Check the game's license and terms. They may forbid modding or translating it.
> - The software is provided as is, with no warranty. You are responsible for what the AI changes.

## What it is

| Part | Meaning |
|---|---|
| This repo | Rules and skills for an AI |
| The AI | Studies the game, then writes its own tool |
| The game's project | Notes, catalog, glossary, tool, and backup for that game only |

## Quick start

1. Give the AI this repo.
2. Give the AI the path to a copy or the game folder you own. Back up first.
3. Tell it: "Read `AGENTS.md` first, then follow the skills in order."
